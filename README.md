
# SecureCaptcha

A reusable numeric image CAPTCHA library for JavaScript applications.

## Features

- Numeric image CAPTCHA
- Distorted CAPTCHA images
- Customizable CAPTCHA settings
- Express.js integration
- Server-side verification
- Challenge expiration
- Attempt limits

## Installation

```bash
npm install secure-captcha
```
